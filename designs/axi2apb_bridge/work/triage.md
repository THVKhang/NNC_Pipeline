| B_test_wrong | For: The spec requires one APB write per beat as W arrives (spec:163, 317, 328), so beats 0 and 1 of the interrupted write are real completed APB writes. The spec says reset gives 'no replay/rollback' (spec:584, ASM-001) and 'No side effect rollback is promised' (spec:333). The completer model itself commits the writes (test:461-462), but the reference model only commits writes in Tracker._finish (test:690), which never runs for aborted records (test:523-528). The mismatch is exactly the 0x22 default init_byte against beat-0 data, at an address that only wc (0x7500) touched. No other check failed: CHK-016 address/strobe checks per transfer, CHK-017/CHK-031 reset checks, and the post-reset tie all passed. So the RTL behaved as specified, and the reference model is missing the side effects of transfers that completed before reset.<br>Against: CHK-027 (contract.json:924) says memory must match an independent model, and OP-005 says 'In-flight work canceled' (spec:331). The test author could have read that as 'the cancelled write has no visible effect'. But no RTL can undo an APB write that already finished, so this reading cannot be met by a design that writes per beat as the spec requires. |

| C_spec_unclear | For: The spec never states directly what memory state the peripheral has after a mid-burst reset.
