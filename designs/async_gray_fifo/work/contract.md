## Assumptions

- Configuration: PARA_AFIFO_DEPTH=8, LPARA_ADDR_W=3, LPARA_PTR_W=4 (thresholds 0..15, unsigned compare), PARA_AFIFO_CELL_TYPE=2 so S=2, PARA_AFIFO_MEM_USE_MACRO=0. Default build has VLSIT_SYNTHESIS undefined (simulation branch with the metastability model).
- Sampling convention: 'X at edge n' is the value sampled at rising edge n before that edge updates registers. 'After edge k' means the cycle that follows edge k, i.e. the value seen at edge k+1.
- Edge counting across domains: 'destination edge 1' is the first rising edge of the destination clock strictly after the source edge. Directed latency tests use periods and phases where write and read edges never coincide.
- An accepted write is i_wr_en=1 and o_full=0 at an i_clk_wr edge. An accepted read is i_rd_en=1 and o_empty=0 at an i_clk_rd edge. This is valid because o_full and o_empty include the software-reset blocks (DEC-027, REQ-SRST-004).
- The write FSM state, req_wr, ack_rd and the internal pointers are not ports. o_sw_rst_busy is used as 'write FSM not in RUN', and its rising edge as the launch edge of req_wr (rule R2). The read release is observed as the resumption of o_underflow pulses with i_rd_en held at 1 on the empty FIFO.
- The lower bound m >= k+S+1 for the fall of o_sw_rst_busy (CHK-011) comes from the handshake: the REL entry edge drops req_wr, and ack_rd can fall only after that. The fall of ack_rd needs at least S write edges to be seen. The minimum crossing latency is S also with the metastability model (DEC-012).
- INV-002 / SVA-001 (full and empty never both 1) is checked only at idle points outside a software reset (CHK-016), not at every edge. Pessimistic flags allow o_full to stay 1 late while o_empty=1 after a fast drain, and o_empty to stay 1 while o_full=1 after a fast fill, so an every-edge cross-domain check would fail on a compliant design.
- CC-02 ('the read side is released while the write side still waits') is read together with REQ-SRST-009: the read side cannot be released while i_rst_n_sw=0 is held, and is released after i_rst_n_sw returns to 1 while the write FSM still waits in REL.
- The metastability model is enabled, disabled and seeded through plusargs whose names are defined by the RTL. 'Model off' runs disable it. Threshold values and clock periods per run are selected by testbench plusargs and set before the hardware reset release.
- For tests that need several threshold values or clock ratios, the same test is run once per value set, since thresholds must not change while the FIFO is in use.
