## Assumptions

- The serial frame format is 8N1 with DATA_WIDTH=8: one start bit at 0, 8 data bits LSB first, one stop bit at 1. The idle line level is 1. The rules do not state this.
- One bit period is 8*prescale clk cycles, taken from the rule baud = Fclk/(8*prescale). Bit-boundary checks allow ±1 cycle, and windows for internal latency (input synchronizers, registered outputs) use the margins given in each check.
- prescale is held constant during a frame and is changed only while tx_busy=0 and rx_busy=0.
- Rule UA-T1.3-04 (which binds the destination) is checked for the DUT as the s_axis destination. On the m_axis side the testbench is the destination, so the rule only constrains stimulus there: the sink takes data only when m_axis_tready=1. The testbench s_axis source holds s_axis_tvalid and s_axis_tdata stable until the handshake.
- For overrun, the approved rule text says the newly received word is discarded and the pending word is kept. The spec quote 'the word is discarded' could be read either way, and the checks follow the approved rule.
- Each test starts with rst=1 for at least 2 rising edges, with rxd=1, s_axis_tvalid=0 and m_axis_tready=1 or as specified. The rules give no reset values, so only idle-state behaviour derived from rule UA-T1.3-06 is checked after reset.
- rxd is driven synchronously to clk by the testbench.
